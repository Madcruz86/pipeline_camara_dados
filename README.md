# Pipeline de Dados Abertos da Câmara dos Deputados

Pipeline de Engenharia de Dados end-to-end que extrai, transforma e modela dados públicos de despesas (CEAP) e deputados da Câmara Federal.

## Stack
- **Ingestão:** Python + AWS S3
- **Transformação:** PySpark (camada Silver)
- **Modelagem:** dbt + PostgreSQL (camada Gold)
- **Orquestração:** Apache Airflow
- **Qualidade de Dados:** Testes dbt
